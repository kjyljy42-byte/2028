# Иллюстрации и фотографии

Все SVG созданы специально для прототипа. `*-placeholder.svg` — подписанные временные изображения, не настоящие фотографии пары или места.

Зарезервированы пути:

- `/assets/few-horses.jpg`
- `/assets/dress-men.jpg`
- `/assets/dress-women.jpg`
- `/assets/couple-medieval.jpg`

Добавляйте настоящие JPG сюда. Прототип не запрашивает отсутствующие фото и использует SVG-заглушки без 404. После добавления фотографии перезапустите Vite; для собранного сайта повторите `npm run build`.

Пути централизованы в `src/data/wedding.js`.
